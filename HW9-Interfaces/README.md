# ДЗ9. Интерфейсы и инверсия зависимостей

[Ответы на задачи 1.1 и 1.2](Theory.md)

Решения 2.1–2.3 запускаются как отдельные консольные проекты на .NET 8. Команды выполняются из корня репозитория.

```sh
dotnet run --project HW9-Interfaces/Task2_1
dotnet run --project HW9-Interfaces/Task2_2
dotnet run --project HW9-Interfaces/Task2_3
```

- **2.1. Бой.** Артур атакует первым. При заданных характеристиках побеждает Мерлин. Маг проверяет состояние цели после первого попадания и пропускает второе, если цель уже погибла.
- **2.2. Предметы.** Для демонстрации у игрока изначально 100 HP и 20 урона. После зелья, меча и свитка у него 130 HP и 60 урона.
- **2.3. Калькуляторы урона.** При базовом уроне 60 и броне 40 один юнит последовательно получает 40, 50 и 66 урона. У него остаётся 44 HP.
